# Course categories

Learning materials now support a category so students can choose what to study from the learning library and classroom book selector. Categories include General English, Conversation, Natural Conversation, IELTS, TOEFL, TOEIC, Business English, English for Kids, Grammar, Vocabulary, Pronunciation, Academic English, Travel English, Reading & Writing, and Exam Preparation.

Apply the database migration `drizzle/0009_learning_material_categories.sql` before deploying. Existing materials default to `general`; admins choose a category when creating new materials.
